# Nazm

**A natively compiled programming language with specified semantics** — deterministic memory
without a garbage collector, structured concurrency, and compiler-checked effects, authority and
provenance. *Nazm* (نظم) is order, the arrangement of verse; its tools are named after stars,
most of them by the Arabic names astronomers still use.

**Status: 0.9.0, a public preview of the 1.0 draft** for macOS on Apple Silicon, with no
compatibility promise until 1.0. Start at [nazm.dev](https://nazm.dev) or the
[0.9.0 release](https://github.com/Nazm-Lang/nazm/releases/tag/v0.9.0).

| [suhail](https://github.com/Nazm-Lang/suhail) | The nazm.dev website and book — *Suhail* (Canopus), the navigators' guide star |
| [alnair](https://github.com/Nazm-Lang/alnair) | Editor extensions for the language server |
| [qutb](https://github.com/Nazm-Lang/qutb) | Installer and toolchain version manager — *Qutb*, the pole star |
| [thuraya](https://github.com/Nazm-Lang/thuraya) | Package registry — *Thuraya*, the Pleiades |
| [homebrew-tap](https://github.com/Nazm-Lang/homebrew-tap) | `brew install nazm-lang/tap/nazm` |
| [tree-sitter-nazm](https://github.com/Nazm-Lang/tree-sitter-nazm) | Tree-sitter grammar |
| [setup-nazm](https://github.com/Nazm-Lang/setup-nazm) | GitHub Action that installs the toolchain |
| [hamal](https://github.com/Nazm-Lang/hamal) | Browser playground |
| [mira](https://github.com/Nazm-Lang/mira) | Benchmarks and performance tracking |
